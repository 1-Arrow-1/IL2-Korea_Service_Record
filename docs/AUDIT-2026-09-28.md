## Medium priority issues

### AUD-1 — FIXED 28 Sep — a long name is silently cut off the display case's plate

**Severity:** Medium
**Component:** shadowbox / engraving
**Countries affected:** all with a case (601, 501, 503)
**Files:** `korea_service_record/static/css/detail.css:1419-1423`;
`korea_service_record/static/js/app.js`, `fitPlate()`
**Problem:** `.sbox-plate-text` is `overflow: hidden; white-space: nowrap`, and
`fitPlate()` stops shrinking the engraving at 30% of the plate's height. A name
longer than the brass can hold at that floor is clipped, with no ellipsis and
nothing else to show that anything is missing.
**Expected:** the whole name, or a visible sign it was shortened.
**Actual:** the engraving is cut off mid-word at the edge of the plate.
**Evidence:** CONFIRMED. A throwaway career named
`Maximilian-Wolfgang Þorvaldur von Hohenzollern-Sigmaringen O'Shaughnessy-Ćirković`
at 1366x768. `fitPlate` had already fallen back to its initial form and the
measured text still exceeded the field
(`span.scrollWidth > holder.clientWidth`). Script: `scratchpad/audit_stress.py`.
**User impact:** low in practice — it takes roughly 70 characters, and the game's
generated names are short. But a player who names a custom career at length sees
his own name truncated on the one page built to be shown off.
**Likely root cause:** the fit has a lower bound and no fallback past it.
**Recommended fix:** below the floor, fall back to surname alone, then to an
ellipsis, so the reader can see something was dropped.
**Regression test:** render the case with a 70-character name; assert
`span.scrollWidth <= holder.clientWidth`.

## Needs verification

Not reached in this pass. None is known to be broken.

- **AUD-V1 — install, upgrade and uninstall were not executed.** The `.iss` was
  audited statically and the layout is sound: the app installs to
  `{localappdata}\IL-2 Korea Service Record` while every piece of user data —
  settings, photos, career backups, the asset cache — lives under
  `{localappdata}\IL2KoreaTracker`, a separate tree, so uninstall cannot reach it.
  `locale_setting.txt` and `game_dir.txt` are written by setup into `{app}`, read
  by `locate.py` and `settings.py`, and removed on uninstall. An actual
  install / upgrade / uninstall cycle still needs running.
- **AUD-V2 — 602 and 603 have no playable career.** Exercised only through
  `KOREA_PREVIEW_RACK`. Assets and ranks resolve; the rendered record for a real
  Navy or Marine career is untested because the game cannot produce one.
- **AUD-V3 — composed medal art was exercised only for 601 in the frozen build.**
  The four eastern careers are new and hold no medals, so `MedalRenderer` was not
  driven for 501/502/503 against the packaged exe. The shadowbox, which uses atlas
  tiles rather than the renderer, did serve for all of them.
- **AUD-V4 — the certificate page and the map's interactions were not swept.**
  The map endpoint returns 200 for every career; panning, zooming and markers were
  not driven.
- **AUD-V5 — deliberate corruption was not tested.** Truncated database,
  unreadable file, malformed `awards.cfg`, read-only cache. The *empty* data path
  was tested and behaves correctly.

## Investigated and dismissed — not defects

Recorded so the same ground is not covered twice.

1. **"The logbook renders blank for four of five careers."** My harness waited for
   `.sheet, #lb-state`; a book with no sorties renders its empty state into a third
   element, `#lb-sheets`. Checked directly: "No sorties flown yet." is present,
   visible and localised in every career. I reported this as confirmed before
   checking, and it was wrong.
2. **`crop-cancel` has no handler.** Caught by the `[data-crop-close]` delegated
   handler at `app.js:2019`.
3. **`.award-list` overflows by 8-9px.** `.award-list li` carries
   `margin: 0 -0.5rem` for a full-bleed hover highlight; the `ul` has no
   `overflow: hidden`, so nothing is clipped.
4. **`.sr-only` overflows by 182px.** That is what screen-reader-only text is.
5. **`_top_combat_award` falls back to `(0, 10**9)` for unknown countries.**
   `VALOUR_LADDER` covers all six, so the fallback is unreachable.
6. **`tunic` looked like a missing file.** It is a coat *key*; `app.js` builds
   `tunic_<key>.jpg` from it. My first country matrix was wrong, not the code.

## Regression suite for future releases

The smallest set that would have caught the real defects of the last two
releases. All six are automatable; none needs a human.

1. `python tools/validate.py` — locale completeness, placeholders, award reachability.
2. `audit_frozen.py` — **drive the built exe, not the source.** The only check that
   would have caught 1.7.5's numpy defect.
3. `audit_sweep.py` — every page x every career x 4 viewports; fail on any
   HTTP >= 400, console error, broken image or document overflow.
4. `audit_country.py` — every country's assets and ranks resolve.
5. `tk_board.py` — build the Career Helper window across every career. This caught
   two crashes in one evening.
6. `audit_stress.py` — a long Unicode name through the record and the case.

Items 2, 3 and 5 are the ones that have actually found shipped bugs. The scripts
currently live in the session scratchpad and should be moved into `tools/` if
they are to survive.
