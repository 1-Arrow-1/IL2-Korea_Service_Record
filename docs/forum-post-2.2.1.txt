IL-2 Korea Service Record 2.2.1 — hotfix


Gentlemen,

A quick fix for 2.2.0. Please update if you are on it.

- Undo works as described. Copying a backup from
  %LOCALAPPDATA%\IL2KoreaTracker\backups over your career file now sticks: the
  tracker notices and leaves the career as you restored it. In 2.2.0 it
  corrected the file again the next time it opened it.
- No more backup pile-up. A backup is made only when the tracker actually
  writes, never just from opening a career or while the game has the file busy.
- Safer writes. The record of your original values is saved before the career
  file is changed, so an interrupted write can no longer lose it.

The napalm bug is still in the game as of hotfix 1.004b, so the correction
stays.
